What is FORGE?

FORGE generates controlled candidate wordlists from user-defined inputs. It is designed for people who need predictable generation rather than a basic random-password button.

Smart Generation

Generate English-like candidates using structured word construction and controlled variations.

Scrambled Generation

Produce candidate arrangements using controlled permutation and scrambling workflows.

Exhaustive Generation

Explore defined candidate spaces when systematic coverage is required.

Length Control

Define required candidate lengths so generation stays inside the intended search space.

Generation Limits

Set maximum candidate counts instead of allowing uncontrolled generation to consume enormous amounts of time and storage.

Resume Workflows

Continue supported generation workflows from saved state rather than rebuilding everything from the beginning.
