FORGE by Vincent Ihura

Controlled candidate generation.

FORGE is a password and word generation engine built around control, repeatability and configurable candidate generation workflows.

What FORGE does

Password and word candidate generation is often the first checkpoint in an authorized security-testing workflow. FORGE provides a structured way to create candidate sets from defined inputs rather than relying on uncontrolled or repetitive generation.

Built around control.

Smart Generation

Generate English-like candidates and controlled variations from supplied inputs.

Scrambled Generation

Explore alternative arrangements when ordering and variation matter.

Exhaustive Generation

Generate controlled combinations where broader candidate coverage is required.

Limits & Length

Control generation volume and candidate length instead of allowing an unbounded process to consume resources.

Resume Workflows

Continue generation from saved state and avoid unnecessarily repeating completed work.

Multiple Platforms

The current public release targets Linux x86-64, with additional platform support planned separately.

Built for authorized use.

FORGE is intended for legitimate password management, research, development and authorized security testing. Only use generated candidates against systems, accounts or environments for which you have explicit permission.
