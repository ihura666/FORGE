FORGE Guide

Understand the engine.

FORGE is an advanced word and password generation engine designed for controlled, repeatable candidate generation. It gives you control over how candidates are constructed, traversed, limited, saved and resumed.

What can FORGE do?

FORGE provides multiple generation strategies so a workflow can use targeted construction, permutations or broader controlled candidate exploration instead of relying on one fixed generation method.

Smart Generation

Produces English-like candidates and controlled variations for workflows where structured word construction is useful.

Scrambled Generation

Explores permutations and reordered combinations according to the selected generation strategy.

Exhaustive Generation

Provides controlled combination generation when broader candidate coverage is required.

Generation Limits

Set candidate limits and required lengths so large generation jobs remain deliberate and manageable.

Traversal Control

Use available traversal strategies to determine how the candidate space is explored.

Resume Support

Continue supported generation workflows from saved state instead of unnecessarily starting from zero.

Security and authorized use

FORGE is a candidate-generation utility. It should be used only with systems, accounts, credentials, datasets and environments that you own or have explicit permission to test.

FORGE does not grant permission to access another person's account or system. Authorization comes from the owner of the system, not from the software being used.
