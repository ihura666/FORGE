What is FORGE?

FORGE is a word and password generation engine designed around controlled candidate generation rather than uncontrolled guessing.

Controlled Generation

Define the words, numbers, symbols, lengths and generation rules that shape the candidate space.

Multiple Strategies

Select different generation modes and traversal strategies depending on the structure of the candidate space.

Candidate Limits

Set generation limits so large searches can be controlled instead of allowing an unrestricted combination explosion.

Exact Lengths

Restrict generated candidates to a required length when the workflow demands exact-size candidates.

Existing Wordlists

Load previous output and avoid unnecessarily rebuilding candidates that have already been generated.

Resume Support

Continue longer generation workflows from saved state instead of restarting the entire process.

How the workflow works.

The basic FORGE workflow is deliberately structured. Each stage controls what enters the candidate space and how that space is traversed.

01

Define the inputs

Provide the keywords, numerical values and symbols that should participate in candidate construction.

02

Choose the generation mode

Select Smart, Scrambled or Both depending on whether you want structured word construction, permutations, or a combination of approaches.

03

Control the search

Configure candidate limits, required length, traversal strategy and other generation constraints before the engine begins producing output.

04

Generate and save

FORGE produces candidates according to the selected rules and writes the resulting wordlist to the configured output file.

05

Resume when necessary

Long-running workflows can use saved state so the process can continue without rebuilding the same search from the beginning.

06

Inspect the result

Treat the generated wordlist as an explicit, inspectable representation of the candidate space you configured.

Generation modes.

Different modes produce different structures. The correct choice depends on what you are trying to model or examine.

Smart Generation

Purpose: prioritize English-like word construction and controlled variations.

Scrambled Generation

Purpose: explore rearranged structures and permutations when the order of components matters.

Both

Purpose: combine Smart and Scrambled approaches when broader candidate exploration is required.

Exhaustive

Purpose: explore controlled combinations across the available input space while respecting the configured limits.

The important distinction.

Generation mode determines how candidates are constructed. Traversal determines the order in which the available candidate space is explored. They are related, but they are not the same control.

Traversal strategies.

FORGE can organize candidate exploration using different traversal strategies. The strategy affects ordering, not the underlying meaning of the generated candidates.

Sequential

Process candidates in their natural generation order. Useful when deterministic progression matters.

Priority

Process candidates according to the priority structure defined by the generation workflow.

Rotation

Rotate the ordering of candidate components to expose different structural arrangements.

Alphabetical

Organize candidates alphabetically for predictable inspection and easier output analysis.

Random

Explore candidates in a randomized order when a deterministic sequence is not required.

Controlled Exploration

Combine traversal choice with candidate limits and exact-length requirements to keep large searches manageable.

Before you generate.

Large candidate spaces grow quickly. A disciplined configuration prevents a useful experiment from becoming an unnecessarily enormous computation.

Set a candidate limit Prevent unrestricted generation from consuming excessive time or storage.
Set the required length Generate only candidates that match the length required by your workflow.
Review your inputs Every keyword, number and symbol can multiply the size of the candidate space.
Choose traversal deliberately Ordering can affect which candidates are reached first during a limited run.
Reuse existing output Load previous wordlists when continuing a generation workflow rather than unnecessarily recreating output.
Keep saved state Long-running jobs are easier to continue when their progress state is preserved.
Use FORGE only for systems, accounts, datasets and security testing environments that you are authorized to examine. FORGE is a generation engine. It does not turn unauthorized access into authorized access.
