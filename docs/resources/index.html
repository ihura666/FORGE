What is FORGE?

FORGE is a controlled word and password candidate-generation engine designed around repeatable generation workflows.

Controlled candidate generation

Instead of treating generation as one unrestricted operation, FORGE provides controls for how candidates are constructed, traversed and written.

Depending on the selected workflow, users can work with smart generation, scrambled permutations and exhaustive generation. Generation limits and required candidate lengths can also be used to keep large workloads bounded.

This makes FORGE useful for legitimate security testing, development, research, controlled experiments and other authorized workflows where candidate generation is required.

Core capabilities

  • Smart word generation
  • Scrambled permutations
  • Exhaustive generation
  • Candidate-length control
  • Generation limits
  • Traversal strategies
  • Resume and saved-state workflows
