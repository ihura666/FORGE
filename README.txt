FORGE
Advanced Word & Password Candidate Generation Engine
=====================================================

FORGE is a controlled candidate-generation engine designed for
security research, authorized testing, development workflows and
structured word and password generation.

It provides multiple generation strategies, configurable limits,
candidate-length control, traversal methods and resumable workflows.

WHAT FORGE DOES
---------------

FORGE allows you to construct and explore candidate sets using
controlled generation strategies.

Core capabilities include:

- Smart word generation
- Scrambled/permutation generation
- Exhaustive generation
- Candidate-count limits
- Required candidate length
- Traversal strategies
- Existing-wordlist support
- Saved-state and resume workflows
- Controlled output generation
- Linux x86-64 release


GENERATION MODES
----------------

SMART

Generates structured, English-like candidates and controlled
variations.

SCRAMBLED

Explores reordered and permuted candidate structures.

EXHAUSTIVE

Explores controlled combinations when broader candidate coverage
is required.

The available modes allow the generation strategy to be selected
according to the intended workflow rather than forcing every task
through one algorithm.


CONTROL
-------

FORGE is designed around controlled generation.

You can configure parameters such as:

- Maximum candidate count
- Required candidate length
- Input keywords
- Numeric values
- Symbols
- Traversal strategy
- Existing wordlists
- Saved generation state

This allows large candidate-generation jobs to remain bounded and
repeatable instead of generating an uncontrolled number of results.


TRAVERSAL
---------

FORGE supports different traversal strategies for exploring the
candidate space.

Available strategies include:

- Sequential
- Priority
- Rotation
- Alphabetical
- Random

The appropriate traversal method depends on the workflow and the
desired ordering of generated candidates.


RESUME SUPPORT
--------------

Long generation jobs do not necessarily need to start from zero.

FORGE can use saved state and existing output information to support
resumable workflows where supported by the selected generation mode.

This is useful when generation is interrupted or when a large
candidate space needs to be processed across multiple sessions.
